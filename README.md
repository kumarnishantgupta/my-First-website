# 1placeAds – Digital & Traditional Ad Agency Website

**1placeAds** is a fully responsive and modern website designed for a hybrid advertising agency offering both digital and traditional ad services. This is a frontend-only project created using HTML, CSS, and JavaScript.

## 🚀 Live Demo

👉 [Visit Website](https://kumarnishantgupta.github.io/my-First-website/)  


## ✨ Features

- Responsive layout for desktop and mobile
- Clean and modern UI
- Service-based navigation (Google Ads, Social Media, Print Ads, etc.)
- Animated testimonials and sections (upcoming)
- Easy-to-update HTML structure

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- Git & GitHub
